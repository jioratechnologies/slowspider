Backup & sync

☁ Automatic cloud backup

Connect a backup file inside a folder your cloud already syncs — iCloud Drive, Google Drive, Dropbox or OneDrive. The organizer then saves to it on every change, and your cloud service copies it to all your devices. No account or server needed.

Not connected
Automatic file sync needs Chrome or Edge. In Safari or Firefox, use Manual backup below — it works everywhere.
⬇ Manual backup

Download a full backup file, or import one to restore or move to another computer. Keeping it in a cloud folder is a simple, universal backup.

🤖 Let an assistant manage it

This box is your data as text. Copy it to hand to any AI assistant — Claude or another — with your permission, then paste its updated version back and Apply to load the changes.
